# SailPoint IdentityIQ – IAM Project

Hands-on Identity and Access Management learning project focused on SailPoint IdentityIQ concepts and practical implementation scenarios.

## Topics Covered

- Joiner, Mover, Leaver (JML)
- Application Onboarding
- Account Aggregation
- Identity Correlation
- Provisioning and Deprovisioning
- Identity Refresh
- Access Certification
- RBAC and Entitlements
- Troubleshooting Scenarios

## Technologies

- SailPoint IdentityIQ
- Java
- BeanShell
- SQL
- REST API
- Active Directory

## Project Objective

This project demonstrates practical understanding of SailPoint IdentityIQ and common IAM processes through hands-on learning and implementation scenarios.
